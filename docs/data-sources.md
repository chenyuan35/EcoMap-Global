# Data sources

EcoMap Global currently ships with a small demo dataset so the application can run without third-party API keys.

Planned public-data adapters include:

- Open-Meteo for weather and climate observations
- OpenAQ-compatible feeds for air-quality measurements
- World Bank open datasets for country-level environmental indicators
- OpenStreetMap for basemap tiles and geographic context

Any production adapter should preserve source attribution, collection timestamps and units, and should respect the upstream provider's rate limits and terms of use.
